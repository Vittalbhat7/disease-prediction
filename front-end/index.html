How it works

  1. Enter the inputs

    Fill in the required features for the module you chose.

  2. Submit to the API

    The form validates your values and sends them to the configured prediction API.

  3. Review the result

    The page shows the prediction the model returned, with its probability when the API provides one.

About the project

HealthPredict AI is an educational machine-learning project. It demonstrates how a plain HTML, CSS and JavaScript frontend connects to Python FastAPI services that serve scikit-learn models.

The frontend never calculates predictions itself. Every result comes from the backend.
